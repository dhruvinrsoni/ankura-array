Data source

Bookmarklet is the working real-data path: zero infrastructure, ~10 s per refresh. Mock is the default and shows fake but plausible data for validating the UI. Live (BMS) requires a self-hosted Cloudflare Worker — public proxies are blocked by BMS's WAF (see WORKER_PROXY.md).

📌 BMS Bookmarklet

  1. Drag the link below to your browser's bookmarks bar (do not click it on this page — it has nothing to extract).
  2. Open bookmyshow.com, navigate to one of your pinned theater's showtimes page (e.g. Cinepolis Seasons Mall → today's shows).
  3. Click the bookmark in your bar → it copies showtime JSON to clipboard → switch back to Mancha-Matrix → paste into the box below → Import.
  4. Repeat for the other theaters. Switch source above to Bookmarklet, then go to Matrix tab.

About
